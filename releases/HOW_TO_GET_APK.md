# دریافت APK کامپایل‌شده

فایل باینری APK از طریق این اتصال‌دهنده به‌صورت مستقیم سخت آپلود می‌شود.

## راه سریع
از چت Grok فایل `RegionalPower.apk` را دانلود کن (نسخه 1.0.0).

## از روی سورس Godot
```bash
git clone https://github.com/mrfokolaii-jpg/regional-power.git
# Godot 4 → Import پوشه godot → Export → Android
```
